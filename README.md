# Praktikum-Laravel1
Website Katalog Menu Kafe Nusantara 

Deskripsi Project

Website Katalog Menu Kafe merupakan aplikasi berbasis web yang dibuat menggunakan framework Laravel. Website ini dirancang untuk menampilkan informasi menu makanan dan minuman pada Kafe Nusantara agar pengunjung dapat melihat berbagai pilihan menu dengan mudah.

Tujuan

1. Membuat website katalog menu kafe.
2. Memudahkan pengunjung melihat daftar makanan dan minuman.
3. Menampilkan informasi menu secara menarik dan terstruktur.
4. Menerapkan penggunaan framework Laravel dalam pengembangan website.

Teknologi yang Digunakan

- Laravel
- PHP
- HTML
- CSS
- JavaScript
- MySQL
- Visual Studio Code

Fitur Website

- Halaman Beranda
- Halaman Katalog Menu
- Informasi makanan dan minuman
- Halaman Kontak
- Tampilan website yang sederhana dan mudah digunakan

Struktur Project

Project ini menggunakan struktur folder Laravel, antara lain:

- app
- bootstrap
- config
- database
- public
- resources
- routes
- storage
- tests

Cara Menjalankan Project

1. Clone repository:
   
   git clone URL_REPOSITORY

2. Masuk ke folder project:
   
   cd katalog-menu-kafe

3. Instal dependency:
   
   composer install

4. Salin file konfigurasi:
   
   cp .env.example .env

5. Buat application key:
   
   php artisan key:generate

6. Atur konfigurasi database pada file ".env".

7. Jalankan migrasi database:
   
   php artisan migrate

8. Jalankan website:
   
   php artisan serve

9. Buka alamat berikut di browser:
   "http://127.0.0.1:8000"
