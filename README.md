Website Katalog Menu Kafe Nusantara

Deskripsi Aplikasi

Website Katalog Menu Kafe Nusantara merupakan aplikasi berbasis web yang dibuat menggunakan framework Laravel. Website ini bertujuan untuk memberikan informasi mengenai berbagai pilihan makanan dan minuman yang tersedia di Kafe Nusantara.

Pengunjung dapat melihat halaman beranda, daftar menu, kategori makanan dan minuman, informasi tentang kafe, serta halaman kontak.

Fitur dan Halaman Website

1. Beranda: Menampilkan halaman utama dan informasi sambutan.
2. Menu: Menampilkan daftar makanan dan minuman.
3. Kategori: Menampilkan kategori menu.
4. Tentang: Menampilkan informasi profil kafe.
5. Kontak: Menampilkan informasi kontak kafe.

Implementasi Routing, Controller, dan View

1. Routing

Routing digunakan untuk mengatur alamat URL agar setiap halaman website dapat diakses.

2. Controller

Controller digunakan untuk mengatur alur aplikasi dan menghubungkan permintaan pengguna dengan halaman yang ditampilkan.

3. View

View menggunakan Blade Template Laravel untuk menampilkan antarmuka website kepada pengguna.

Teknologi yang Digunakan

- PHP
- Laravel
- HTML
- CSS
- JavaScript
- Blade Template

Cara Menjalankan Proyek

1. Clone repository GitHub.
2. Masuk ke folder proyek.
3. Jalankan "composer install".
4. Salin ".env.example" menjadi ".env".
5. Jalankan "php artisan key:generate".
6. Sesuaikan konfigurasi database jika diperlukan.
7. Jalankan "php artisan serve".
8. Buka browser dan akses "http://127.0.0.1:8000".
